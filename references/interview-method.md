# Interview Method

## 定位

**项目反向拆解 + 证据验证 + 面试追问 + 口述边界控制。**

必须避免：

1. Agent 先读完全库 → 用自己的理解开考（用户变成答题机）  
2. AI 长篇讲解 → 用户点头 → 面试仍崩  
3. 裸 0–5 分数、无缺口说明  
4. 把项目里「存在的东西」都说成面试可讲  

成功路径：

```text
读 session-state → 最小事实地图 → 用户自述 → 追问/打断
  → 用户定位证据 → 短解释 → 重测
  → 更新分数三元组 + Interview Status + session-state
  → mock 结束 → Top 3 deep-dive GAP
```

交互细节（续练、角色、效果词打断、口述、标签显隐）见 [interview-interaction.md](interview-interaction.md)。
## 优先级

**代码事实 > 用户记忆 > AI 猜测**

## 最小事实地图（测绘员）

### 要什么

面试索引，不是项目白皮书：

- 入口  
- 主链路 ≤6 步  
- 核心状态  
- 工具名列表  
- 外部服务  
- 持久化对象  
- 编排层与 Agent 边界（若有）  

### 停止条件

- 文件预算约 **8–12**；map **≤25 行**  
- 识别够用即停；细节留到当前 GAP 再打开文件  
- **不得**在开场向用户讲解实现  

### 反模式

读 50 个文件 → 巨大 project-map → 「根据实现，正确答案是…」→ 考用户  

## 三角色

| 角色 | 何时 | 做什么 |
|------|------|--------|
| 测绘员 | 开场 / 进入新 GAP 前 | 最小地图或按需补读当前主题 |
| 面试官 | 默认 | 追问、GAP、三元组评分、Status |
| 辅导员 | 仅 Hard Rules 第 5 步 | ≤3 段，立刻重测 |

## 评分反伪精确

禁止只写 `数据流 2/5`。

必填：

1. **已证明什么**（用户已说清且 ideally 有证据）  
2. **尚未证明什么**（具体缺口，不是「还不太熟」）  
3. **升到下一级要回答的那一题**  

例：

```text
Supabase / Data Flow：2/5
已证明：能说明 Research Card 会写入数据库。
缺口：不知道哪个函数写；不知道写入失败时系统行为。
升到 3：解释为什么放 Supabase，以及失败时系统行为。
目标等级：核心数据流 → 4；若本轮只练外围读写时机 → 可先盯 3。
Interview Status：FRAGILE
```

数字是索引；**缺口与升级题**才是训练指令。

## 目标等级（省训练成本）

不要让 Browserless 内部实现也刷到 4。

核心链路（产品问题 → 为何 Agent → 架构 → 核心数据流 → Loop → 主工具 → 产品决策 → 效果口径）→ 通常冲 **4**。  
外围基础设施 → **2–3**。  
效果句无数据 → 降 Status，不假装 5。

## Interview Status

| Status | 用途 |
|--------|------|
| SAFE | 主叙事 |
| QUALIFIED | 主叙事但必须带贡献/深度限定 |
| FRAGILE | 先 deep-dive；面试慎用 |
| DO NOT CLAIM | 不提或只承认存在、不装懂 |

QUALIFIED 示例口径：

> 我负责整体研究流程和工具选型；Browserless 的具体调用由 Cursor 协助完成。我能解释它在链路中的输入输出和失败处理。

## GAP 与持续训练

格式：`GAP-007`

字段：主题、L 层、A/B/C、当前分、目标分、已证明、缺口、升级题、Status、建议文件入口。

`mock-*` / `pressure` / `diagnose` 结束必须输出：

```text
今天最值得 deep-dive 的 3 个问题
1. GAP-007 …
2. GAP-012 …
3. GAP-003 …
下次直接说：deep-dive GAP-007
```

## 模式要点

### diagnose
最小地图 + 浅问 + 星级 + Top GAP；不讲课。

### deep-dive
可跟模块名或 `GAP-xxx`。到 **目标等级** 即停，不强制全维 4。

### mock-pm / mock-technical
只追问与记 GAP；结束给 Top 3 deep-dive。

### pressure
打效果数据与角色边界；逼出 SAFE/QUALIFIED 改口或 DO NOT CLAIM。

## 反模式

- 全库精读开考  
- 题海但不查代码  
- 分数仪式感  
- 外围强刷 4  
- Ticket 完成度当理解度  
- 压力模式人身攻击
