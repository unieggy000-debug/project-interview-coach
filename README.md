# project-interview-coach

项目主要由 AI 写完了，但面试讲不清？用这个 Skill：**反向拆解 + 证据验证 + 模拟面试**。

---

## 安装（复制两行发给你的 AI）

```text
请帮我安装这个项目面试 Skill：
https://github.com/unieggy000-debug/project-interview-coach
```

装完后按提示 **新开对话**，打开正式项目，发送：`开始项目面试`

> 安装细节写在仓库 [`INSTALL.md`](INSTALL.md) 里，给执行安装的 AI 看，你不用管。

---

## 常用指令

| 发送 | 作用 |
|------|------|
| `开始项目面试` | 开练 |
| `菜单` | 启动面板 |
| `mock-pm` | 产品模拟面 |
| `deep-dive Agent Loop` | 深挖 |
| `explain Agent Loop 30s` | 口述 |
| `pressure` / `继续` | 压力 / 续练 |

图文：[`usage.html`](usage.html) · 提示词文件：[`INSTALL-PROMPT.md`](INSTALL-PROMPT.md)
