# project-interview-coach

项目很多是 AI 帮你写的，能跑，但面试官一追问就虚？

这个 Skill 帮你把项目**真正讲明白**：它不当百科老师，而是像面试官一样追问，逼你去代码里找证据，再练到能口述。

---

## 怎么安装

把下面两行复制，发给你正在用的 AI：

```text
请帮我安装这个项目面试 Skill：
https://github.com/unieggy000-debug/project-interview-coach
```

装完后：**新开一个对话** → 打开你的正式项目 → 发送 `开始项目面试`。

---

## 它能干什么

| 能力 | 说明 |
|------|------|
| **摸底** | 快速看出你对项目哪一层还不熟（产品 / 流程 / Agent / 数据 / 工程） |
| **模拟面试** | 按产品经理或技术面连续追问，像真场面 |
| **深挖漏洞** | 专啃一个模块或某个不会的点（例如 Agent Loop、数据库怎么读写） |
| **证据验证** | 你说「会自动选工具」→ 它让你指出代码在哪，不让你背空话 |
| **口述练习** | 限时 30 秒 / 2 分钟讲清，缺什么马上让你重说 |
| **压力追问** | 专门打「提高效率」却没数据这类说法 |
| **跨天续练** | 进度记在项目里的 `.interview-coach/`，下次接着练 |

适合：AI 产品经理面试、技术项目深挖、以及「代码是 AI 写的、我要补理解」的情况。

## 不知道发什么？看这里

直接发下面任意一句即可（发 `菜单` 也会再弹出这份清单）：

| 你发送 | 它会做什么 |
|--------|------------|
| `开始项目面试` | 自动开练（第一次一般是摸底） |
| `菜单` | 弹出常用指令（迷茫时先发这个） |
| `mock-pm` | 模拟 AI 产品经理面试 |
| `mock-technical` | 模拟偏技术的项目追问 |
| `deep-dive Agent Loop` | 专啃某一个模块（把名字换成你的也行） |
| `deep-dive GAP-007` | 专啃上次记下的某个漏洞编号 |
| `explain Agent Loop 30s` | 不看代码，限时口述（也可改成 2min / 5min） |
| `pressure` | 压力模式，专打效果和数据 |
| `继续` | 按上次进度接着练 |
