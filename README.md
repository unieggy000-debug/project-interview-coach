# project-interview-coach

项目很多是 AI 帮写的，能跑，但面试一追问就虚？简历上的写法也对不上代码？

这个 Skill 像面试官一样追问 **项目细节 + 简历表述**，逼你去代码里找证据，并标出简历哪里该改。

---

## 怎么安装

复制两行发给你的 AI：

```text
请帮我安装这个项目面试 Skill：
https://github.com/unieggy000-debug/project-interview-coach
```

装完后按它的说明准备 **项目 + 简历**，再发 `开始项目面试`。

---

## 怎么开始

**项目（二选一）：**

- 在 Cursor 用「文件 → 打开文件夹」打开你的项目，再新开对话；或  
- 直接把项目路径发给 AI（例如 `C:\AAA\projects\vision-agent`）

**简历（任选一种）：** 拖文件进对话 / 发路径 / 粘贴正文  

然后发送：`开始项目面试`

---

## 它能干什么

| 能力 | 说明 |
|------|------|
| **项目摸底 / 深挖** | 产品、流程、Agent、数据、工程一路追问 |
| **成绩单 + 错题本** | 每场结束打分，错题可下次接着练 |
| **对照简历提问** | 简历怎么写的，就按那句往下扎，看能不能被代码证明 |
| **简历可改点** | 输出哪里夸大、含糊、缺数据，给改写方向 |
| **证据验证** | 不让你背空话，卡住就去项目里找 |
| **口述 / 压力面** | 限时讲清；专打「提高效率」却没数据 |

---

## 不知道发什么？

发 `菜单`，或直接用：

| 发送 | 作用 |
|------|------|
| `开始项目面试` | 开练（需项目 + 简历） |
| `菜单` | 常用指令 |
| `mock-pm` / `mock-technical` | 产品面 / 技术面 |
| `deep-dive Agent Loop` | 深挖模块 |
| `explain Agent Loop 30s` | 口述 |
| `pressure` | 压力追问 |
| `结束` / `出成绩` | 本场成绩单 + 错题本 |
| `简历反馈` | 看简历可改清单 |
| `继续` | 续练 |
